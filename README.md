# N325MA MU-2 Study Cards

Mobile flash cards for **N325MA** (MU-2B-26 with TPE331-10 STC).

**Intended live URL:** https://kevin-idlex.github.io/n325ma-cards/

Study aids only — always **VERIFY IN AFM SUPPLEMENT (-10 STC)** and checklist **YET06249A**.

## Enable GitHub Pages (one-time)

The Actions `GITHUB_TOKEN` can *deploy* to Pages but **cannot create** the Pages site.

1. Open https://github.com/kevin-idlex/n325ma-cards/settings/pages
2. Under **Build and deployment → Source**, choose **GitHub Actions**
3. Re-run **Actions → Deploy GitHub Pages → Run workflow** (or push any commit)

After that, the workflow deploys on every push to `main`.
